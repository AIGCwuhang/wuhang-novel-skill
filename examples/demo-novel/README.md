# 《渡口账册》微型原创示例

此例由 AI 为演示工作流编写，不来自作者既有小说或旁边的真实项目。采用 300–900 字的缩短章节范围，展示文件如何衔接，不代表普通连载章节长度或商业成效。

阅读顺序：

1. [作者预期](1-边界/预期.md) 与 [文风](1-边界/1.2_文风.md)。
2. [设定案](2-设定/2.2_新书设定案.md) 与 [人物](2-设定/2.4_主要角色设定表.md)。
3. [总纲](3-大纲/3.1_全书结构总纲.md)、[卷纲](3-大纲/第一卷_完整卷纲.md)、[章纲](3-大纲/第一卷_章纲.md)。
4. [第一章草稿](4-正文/第1章_草稿.md) 与 [审稿、自检](5-审查/第1章_自检与审稿.md)。
5. 查看 [总控](SOLOENT.md)、[角色状态](.novelkit/memory/character_state.md) 与 [伏笔表](.novelkit/memory/foreshadowing.md) 的写后结果。

本例没有样板书、金手指和额外 API 配置。第二章尚未创作。可在项目根运行：

```sh
python3 skills/wuhang-novel/scripts/count_chinese_words.py --project examples/demo-novel
```
