# 编辑器扩展本地安装

本地预览版 `wuhang-novel-skill-0.2.0.vsix` 用于支持 VSIX 的编辑器。未上传扩展市场，也未验证所有兼容编辑器。

[观看视频使用说明（B 站）](https://www.bilibili.com/video/BV1cz8i67ELD/)。视频版本可能不同，但大致创作流程一致；安装方式、路径和界面差异请以当前版本说明为准。

1. 打开扩展面板的菜单，选择“从 VSIX 安装”，选择此文件。
2. 打开本书的文件夹。
3. 打开命令面板，运行“武行: 初始化长篇小说流程 Kit”。
4. 扩展将技能复制到项目 `.agents/skills/wuhang-novel/`，补齐项目文件并打开 `SOLOENT.md`。

初始化不会自动开始写作，也不会调用 API。后续由具备文件读写能力、能加载技能的 AI 工具执行创作。只安装 VSIX 并不等于为任何编辑器接入了 AI 模型。

已有的项目文件一律保留；已有同名技能目录也不会混合覆盖更新。如需升级技能，先备份旧技能目录，再整体替换新技能。作者的小说文件、项目宪法和记忆无需替换。

此扩展不再启动即弹窗；只有主动运行初始化命令时工作。不依赖 Python 完成复制与目录初始化，辅助统计和批量梗概脚本仍需要 Python。
