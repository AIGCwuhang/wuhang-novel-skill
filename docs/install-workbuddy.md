# 在 WorkBuddy 中使用

**状态：导入候选包。** 已准备完整技能资源并做本地结构检查；尚未在真实 WorkBuddy 客户端中执行导入和对话验收，因此不标为“已验证兼容”。

[观看视频使用说明（B 站）](https://www.bilibili.com/video/BV1cz8i67ELD/)。视频版本可能不同，但大致创作流程一致；WorkBuddy 的导入方式以本文和当前客户端为准。

## 下载与导入

1. 从本地 `dist/`，或未来 GitHub Releases，取得 `wuhang-novel-workbuddy-v0.2.0.zip`。
2. 在 WorkBuddy 左侧打开“专家·技能·连接器”，进入技能页签。
3. 选择“添加技能 → 上传技能”，选择该 ZIP。
4. 在“已安装”确认技能存在并启用。
5. 在任务中指定本书的文件夹，输入：

> 使用武行小说创作技能，在这个小说文件夹中初始化项目。我已有部分设定，请先建立索引，保留原稿。

不要选择 VSIX，也不要选择 GitHub 自动生成的完整源码 ZIP。

## 包的结构

此候选 ZIP 根目录直接放 `SKILL.md`，配套 `references/`、`assets/`、`scripts/`、`agents/`。官方文档确认本地技能包上传路径，但未在所查页面规定压缩包嵌套层级；本结构需在目标版本实际验证。

若客户端拒绝此层级，可以另外试通用 ZIP（外层 `wuhang-novel/` 目录），或按当前版本提供的本地技能导入方式处理。先记录错误，不把解压成功视为技能安装成功。

## 初始化和工具

宿主必须能够读取和写入指定项目文件。基础共创无需另外配置 API；初始化和字数脚本使用 Python 3.9+ 标准库。无法运行 Python 时，可由宿主按项目模板逐个补齐文件，不能覆盖旧稿。

可选全书梗概会把选定章节发送到用户配置的 API 服务；默认只预览，实际运行需单独授权。配置说明见技能中的 `references/analyze.md`。

## 实际客户端验收记录应包括

- 客户端版本、系统、导入时间及是否识别中文名称。
- 相对引用能否读取，模板和脚本是否随包保留。
- 空项目初始化、重复初始化、旧稿索引是否正常。
- 写完一章后能否更新角色、伏笔和总控，并在新会话续接。
- 将结果写入 `docs/validation.md`，通过后再更新首页兼容声明。
