# 常见问题

## 我需要会编程吗？

普通共创主要通过对话进行。技能安装和指定小说文件夹后，让 AI 按流程推进。Python 是初始化与统计等工具的运行环境；无法运行时可按模板人工补齐文件。

## Skill、插件、VSIX 要全部安装吗？

不需要。选择适合工具的一个入口。同一个 Skill 装多份可能导致重复发现和混淆。

## 为什么仍叫 SOLOENT.md？

为了兼容旧项目和流程中的章节索引。它现在只是一本书的控制面板，不要求使用 SoloEnt 软件。

## 不提供样板书可以写吗？

可以。用 Define 从作者预期与核心梗开始，后续不强制要求参考书分析文件。

## 可以只审稿、只写章纲吗？

可以。直接说明任务与文件，统一入口只读取相关流程。资料不够时补最关键的缺口。

## 会自动调用收费接口吗？

安装、初始化、统计不调用 API。可选批量梗概脚本默认只预览；配置密钥、模型并显式加 `--run` 才发送所选文本。宿主本身的模型用量按宿主计费，另配 API 的费用由服务商收取。

## 字数和小说平台显示不同？

本工具统计正文中的汉字和标点，不含首行标题、英文与数字，不代表任何平台官方口径。平台验收应以平台自身统计为准。

## 重复初始化会覆盖稿子吗？

初始化只补缺文件。已有宪法、设定、记忆、项目指令与配置不替换。存在同名但类型不符的路径时报告冲突。已有 `.gitignore` 会保留，请合并模板中的密钥忽略项。

## 包为什么写“候选版”？

本地脚本、文件和打包可以自动检查，实际宿主的导入、技能发现和对话行为需要在对应客户端验证。当前范围写在 [验证报告](validation.md)，不把两者混为一谈。

## 是否可以商用、转载或重新打包？

当前版本尚未指定开放许可证。由武行决定具体授权范围后，更新 LICENSE 与首页；请勿仅因仓库公开就推定拥有任意改编或再分发授权。
