# 武行·网文创作 Skill 0.2.0 预览版

融合网文作者、编辑与编剧经验，覆盖新书立项、设定、大纲、正文与审稿的长篇创作工作流。

- 统一入口 `wuhang-novel`，按需使用七个创作模块。
- 项目总控、创作宪法、角色与伏笔记忆，以及可重复初始化工具。
- Codex、WorkBuddy、VSIX 的安装说明与四种发布文件。
- 原创微型示例及 B 站视频说明；视频版本可能不同，大致流程一致。
