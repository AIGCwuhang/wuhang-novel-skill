# 项目约定

此文件统一各流程的路径、输入和状态约定。用户明确要求优先；项目配置和已确认的项目文档优先于技能模板中的默认偏好。本文的路径约定取代旧版散落的路径示例。

## 文件定位

所有下面的输出路径均相对**小说项目根目录**，与技能安装位置无关。流程中简写的文件名也按本表定位。技能内部引用相对技能根目录定位，不再依赖旧版的固定隐藏安装目录。

| 文件 | 内容与写入时机 |
| --- | --- |
| `SOLOENT.md` | 项目控制面板，保留名称以兼容旧项目；不依赖 SoloEnt 软件。§2 世界索引、§3 角色索引、§4 大纲索引、§5 文风、§6 项目规则、§7 当前状态、§8 进度与下一步 |

## 三条输入路径

- **从零开始**：Define → Ideation → Outline → Write ↔ Review。没有参考书时，按项目预期、核心梗、类型边界和目标读者规划，不索要或伪造 `1.3`、`1.4`、`1.5`。
- **参考书模式**：Analyze → Ideation → Outline → Write ↔ Review。注明已读章节范围；没有全书材料时仅做范围内分析。结构统计必须有对应材料支撑。
- **旧稿/灵活模式**：Guide 先确认现有资产和进度，再按缺口补齐。默认先索引，不移动或覆盖原稿；移动、重命名按用户确认的方案做。

各模式均可单独审稿或只做当前环节。长文 `.docx` 等需要宿主提供读取能力；不可仅因文件存在就声称已经读取。必要时让用户导出为 `.txt` 或 `.md`。

## 规则和记忆的边界

模板中的“爽点优先”“三章一小高潮”等是偏向商业连载的默认方法。根据作者的题材、情感承诺和项目配置解释执行，慢热、悬疑、群像等项目可调整。具体措辞禁忌也是作者可修改的偏好。

章节字数以 `.novelkit/config.json` 的 `chapter_words.min`、`max` 为准；默认范围用于章纲和正文。统计口径为正文中的汉字及标点，不含首行标题、英文和数字；不是任何平台的官方统计。用户指定新范围时同步项目配置。若当前交付仅为片段或试读，注明范围，不冒充达标整章。

静态设定可以讨论修订；状态表只记录已确认或已在定稿中实际发生的事实。未采纳草稿、候选剧情不能写成角色的既成经历。写后核对三处：角色状态、伏笔追踪、总控 §7/§8。说明具体变更，未落盘时不可声称“已更新”。

## 安装与项目初始化

安装包中的流程与模板是源资料，项目中的文件属于作者。升级技能不能覆盖已有的项目宪法、设定、正文或记忆。重复初始化只补缺文件，保留现有 `AGENTS.md` 和 `.gitignore`；旧 `.gitignore` 若缺少密钥忽略项，报告并建议用户合并模板条目。

API 梗概是可选增强，普通共创不要求额外 API Key。实际发送前明确所选章节、服务地址、模型和费用由服务商收取；密钥只保存在本地配置，不进入对话、日志或发布包。
